agentcrash

What does this repository start in your coding agent?

A repository can bring its own MCP servers, hooks, plugins and permissions. Some agents act on them the moment you open a session there, before the model has said a word. Paste a public GitHub repository to see what it brings.

Your browser fetches the config files from GitHub and reads them here. Nothing is cloned, nothing is executed, nothing is sent to us.

Before you open an agent in a clone

npx -y https://github.com/croviatrust/agentcrash/tarball/main inspect owner/repo   # read it on GitHub, without cloning
npx -y https://github.com/croviatrust/agentcrash/tarball/main inspect .            # or the folder you are in

Inside the agent, so it happens without you remembering: claude plugin marketplace add croviatrust/agentcrash then claude plugin install agentcrash@agentcrash; gemini extensions install https://github.com/croviatrust/agentcrash; qwen extensions install https://github.com/croviatrust/agentcrash. On pull requests: uses: croviatrust/agentcrash@main.

What "runs on open" means here was measured on the real binaries in headless sessions: Claude Code 2.1.322, Codex CLI 0.167.0, Gemini CLI 0.67.0, Qwen Code 0.27.1, opencode 1.19.5, Crush 0.100.0. Other versions, and interactive sessions of some of these, may ask first. Only config at the repository root is read. Method.
